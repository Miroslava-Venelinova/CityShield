Polygon tester

Runs the Worker's own buildBlockPolygon — bundled straight out of backend/src, never reimplemented — and draws every stage of it: the ways Overpass returned, what the clip window kept, the road bands the blocks are cut from, and each enclosed area with the share of its boundary every street accounts for. Knobs override the constants ingestion defaults to, so a threshold can be argued about against geometry rather than against a rerun test suite.

Input

One request, cached to disk; every build afterwards reads the file. Overpass rate-limits, so re-fetching the same streets to try another threshold is the one thing to avoid.
